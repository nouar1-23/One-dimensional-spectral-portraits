# Одномерные спектральные портреты матриц (MATLAB)

Данный репозиторий содержит программный код на языке MATLAB для визуализации одномерных  спектральных портретов матриц, описанных в научных работах по теории матриц (в частности, в работах Акад. С.К. Годунова и соавторов).

## Описание
Программа `plo.m` является основным исполняемым скриптом. Она предназначена для построения одномерных спектральных портретов и графиков зависимости величин $\log_{10} \delta(r)$ от параметра радиуса окружности $r$.

Эти графики позволяют:
* Анализировать  спектральные портреты матриц $A_0, A_1$ и $A_3$.
* Определять области, в которых спектр матрицы устойчив к малым возмущениям.
* Визуализировать «пики» модулей собственных значений и поведение критерия дихотомии.
